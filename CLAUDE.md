# course_work_parallel_computing

Курсова робота з дисципліни «Паралельні обчислення» (КПІ ім. Ігоря Сікорського, ІПСА, спеціальність 122).
Тема: дослідження та реалізація паралельних обчислень на прикладі пошукової системи з інтеграцією LLM.

Джерело вимог: `Курсова_ПО_2026-2027.pdf` (Додаток А — завдання, Додаток Б — питання для захисту). Вимоги з нього перенесено в `docs/specification/`.

## Ключові обмеження з завдання

- Бекенд мовою C++, Java або C# (вибір ще не зроблено, див. `docs/architecture/decisions/0001-backend-language.md`).
- Власна структура даних для інвертованого індексу з паралельним доступом. Готові бібліотеки індексації не використовуємо.
- Власний thread pool. Не використовуємо готовий пул із фреймворку для цієї частини.
- REST-контракт фіксований: `GET /api/health`, `POST /api/index`, `POST /api/search`, `GET /api/stats`. Змінювати можна лише через оновлення `docs/specification/06-api-specification.md` та `docs/specification/openapi.yaml` і погодження.
- WebSocket `/ws/search` з етапами `query_expansion`, `keyword_search`, `done`.
- Система запускається однією командою `docker compose up`. Сервіси: пошуковий сервер і Ollama. Сервер має відповідати на `GET /api/health`.
