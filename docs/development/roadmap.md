# Roadmap

Schedule follows the self-study table in the assignment (18 weeks).

| Weeks | Stage | Output |
|---|---|---|
| 1 | Receive topic and assignment | Repository created (this step) |
| 2–3 | Read assignment, literature, install Ollama and Docker | Environment running; `ollama` answers locally |
| 4 | Theory chapter (section 1 of report) | Draft of introduction and technology overview |
| 5–7 | System model | Use case, class, sequence, deployment diagrams; model section (section 2) |
| 8–12 | Implementation | Index, thread pool, REST, WebSocket, Ollama, CLI, Web UI |
| 13 | Implementation section of report | Section 3 |
| 14–15 | Testing | Benchmarks, plots, test table; section 4 |
| 16 | Submit | Report PDF and repository link |
| 17–18 | Defense | Demo and questions |

## Attestations
