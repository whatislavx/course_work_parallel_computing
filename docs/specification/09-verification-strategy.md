# 09. Стратегія верифікації і тестування

BDD-сценарії (`05`) — це критерії прийняття, сформульовані через поведінку. Стратегія верифікації ширша: вона містить модульні, конкурентні тести, санітайзери, бенчмарки та інспекції, яких у BDD немає. Кожен тестовий випадок має ID `TEST-<CAT>-NN`.

Методи: **T** — автоматичний тест, **A** — аналіз вимірювань, **I** — інспекція, **D** — демонстрація.

Статус кожного тесту на момент цієї версії: **Не реалізовано** (специфікаційна фаза).
