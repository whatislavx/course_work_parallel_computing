# UML-діаграми першої атестації (TCK-037)

Джерела в PlantUML (`.puml`), по одному файлу на діаграму:

| Файл | Зміст | Джерело |
|---|---|---|
| `use-case.puml` | Use case діаграма (акторі, UC-01…UC-12, зв'язки include) | `docs/specification/04-use-cases.md` §4.2 |
| `class.puml` | Попередня класова діаграма: доменні сутності і компоненти без деталей синхронізації | `07-domain-model.md`, `docs/architecture/components.md` |
| `sequence-uc01.puml` … `sequence-uc12.puml` | Діаграми послідовності для кожного варіанта використання (основний і альтернативні потоки позначені як A/E) | `04-use-cases.md` §§ UC-01…UC-12 |

Статус: синтаксис не перевірено компілятором PlantUML (запуск завантаженого jar заблоковано політикою середовища). Перед здачею діаграми потрібно відрендерити (`plantuml -tsvg docs/architecture/uml/*.puml`) і переглянути результат.

Фінальні class і deployment діаграми — TCK-040 (після реалізації пулу й індексу).
