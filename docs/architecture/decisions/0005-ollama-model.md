# ADR-005: Модель Ollama для розширення запиту

## Status

Accepted (автономна сесія 2026-11-08). Закриває OQ-13. Потребує перегляду власником.

## Context

AD-06 затверджує «малу модель, яку скрипт завантажує під час старту»; точна назва була відкрита (OQ-13). Сервер викликає модель через `/api/generate` з тайм-аутом і без GPU (середовище: 2 vCPU).

## Options

1. `tinyllama` (1.1B): плейсхолдер у попередніх версіях compose; якість розширень низька.
2. `qwen2.5:0.5b` (0.5B): найменша модель з коректними відповідями; швидка на CPU.
3. `qwen2.5:1.5b`: краща якість, але вдвічі повільніша і вдвічі більше пам'яті.

## Decision

Обрано `qwen2.5:0.5b`. Назва задається змінною `OLLAMA_MODEL`, дефолт у `docker-compose.yml`.

## Rationale

Розширення запиту має вкладатися в тайм-аут `OLLAMA_TIMEOUT_MS`, а при збої пошук працює без розширення (FR-021). Найменша модель мінімізує ризик тайм-аутів на слабкому обладнанні.

## Consequences

Якість розширень нижча, ніж у 1.5B. Під час оцінювання можна задати `OLLAMA_MODEL=qwen2.5:1.5b` без зміни коду. Тести використовують імітацію Ollama (`tinyllama` як ім'я в тестовому подвійнику), на них рішення не впливає.
